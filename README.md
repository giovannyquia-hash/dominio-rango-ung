# Dominio y rango · Universidad Nueva Granada

Página de práctica de Matemáticas Básicas con **30 competencias** sobre:

- Notación, intervalos y conjuntos
- Dominio y rango a partir de gráficas
- Dominio de expresiones algebraicas
- Rango y aplicaciones

## Uso local

Abre `index.html` en cualquier navegador. No requiere instalación ni servidor.

## Funcionalidades

- Buscador de competencias.
- Pregunta de ejemplo al pasar el cursor.
- Práctica con respuestas aleatorias y retroalimentación.
- Gráficas SVG de segmentos, rayos, puntos aislados, parábolas, raíces, valores absolutos e hipérbolas con asíntotas punteadas.
- Puntuación guardada en `localStorage`.
- Resumen de criterios: dominio, rango, denominador ≠ 0 y radicando ≥ 0.
